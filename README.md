# JitterScope 2.0 beta

© 2026 SanyLok — автор JitterScope.

Free Windows network monitor for gamers: ping, jitter, packet loss and traffic, with multi-target checks, a compact desktop panel and session history.

**Beta:** интерфейс на русском языке. Диагностические измерения могут отличаться от пинга внутри игры.

Локальная программа для Windows 10/11 x64: мониторинг связи для игроков, компактная панель, сравнение регионов, профили, история сессий и отчёты.

JitterScope распространяется бесплатно. Платная версия и платные функции не планируются. Авторская отметка в программе обозначает автора проекта; условия использования сторонних компонентов приведены в `THIRD_PARTY_NOTICES.md`.

## Запуск

Распакуйте архив в отдельную папку и запустите **JitterScope.exe**. Установка Python не требуется. Предыдущую версию можно сохранить рядом для возврата.

Для запуска исходников нужен Python 3.10+: двойной клик по `setup-and-run.cmd` создаст отдельную `.venv` и установит закреплённые библиотеки. Вручную: `python -m pip install -r requirements.txt`, затем `python jitterscope.py`.

## Что исправлено после 1.2

- Ошибка или тайм-аут DNS выбранной цели больше не останавливают шлюз, контроль, дополнительные узлы и трафик. Неудачный DNS повторяется автоматически через 30 секунд; неразрешённые дополнительные адреса — через 60 секунд.
- Рост задержки только у контрольного узла получает отдельную подсказку. Сравнение использует нижний 20-й процентиль базы вместо единственного минимального ответа.
- По умолчанию цель `1.1.1.1` и контроль `8.8.8.8` различаются. Для других целей контроль — `1.1.1.1`.
- Цвет основной цифры и мини-панели учитывает потери/тайм-ауты, разброс, ошибки и достаточность выборки. Быстрый ответ после серии потерь больше не даёт зелёную оценку.
- Код разделён на модули измерений, статистики, хранения, профилей, диалогов, интерфейса и запуска.

## Ежедневное использование

Выберите диагностический адрес из списка или введите IPv4/домен и нажмите «Применить». Каждый цикл измеряет цель, следующий шлюз маршрута Windows и внешнюю контрольную точку. Интервал — примерно секунда, тайм-аут запроса — 900 мс. Исходный адрес и трафик можно привязать к адаптеру телефона. Windows продолжает определять маршрутизацию, включая влияние VPN.

Шлюз ищется для контрольного адреса и проверяется на соответствие выбранному адаптеру. Если шлюз недоступен или у VPN нет отдельного следующего узла, остальные измерения продолжаются. Маршрут перепроверяется каждые десять секунд. Отсутствие ICMP-ответа не доказывает обрыв интернета.

Крупная цифра и график относятся к выбранной цели. Шлюз и контроль имеют собственную историю и статистику. Скользящее окно — 60 измерений; полная история записывается отдельно.

**Двойной клик по заголовку или Ctrl+M** переключает мини-панель: три задержки и входящий/исходящий трафик. История продолжает записываться. Знак `!` означает ошибку, `—` — отсутствие ответа.

Кнопка **−** сворачивает программу в трей; если трей недоступен — обычным способом. Двойной клик по значку трея показывает/скрывает окно. В меню трея есть полное окно, мини-панель, история, папка данных, сведения о программе и выход. **× / Alt+F4** завершает приложение с записью последних данных.

Внизу полного окна находятся прозрачность и «Поверх окон». При небольшом экране полное содержимое прокручивается. Ctrl+H или Ctrl+E открывают историю/отчёты. Горячие клавиши действуют, когда окно приложения активно.

## Регионы и параллельные проверки

Нажмите **«Регионы…»**, отметьте до пяти дополнительных адресов и примените выбор. Они проверяются по ICMP одновременно с тремя базовыми точками. В таблице видны текущая задержка, среднее, P95, потери/тайм-ауты и размер выборки. Для подсказки о более благоприятном результате требуется не менее пяти успешных ответов узла. Разные диагностические адреса не гарантируют такой же порядок качества игровых матчей.

Каталог включает 25 пресетов: Cloudflare, 11 узлов Fortnite, 7 диагностических адресов VALORANT, 5 SDR-ретрансляторов CS2 / Dota 2 и EU-узел Overwatch. Источники и ограничения доступны по ссылке под выбором сервера. Каталог статический; подтверждение назначения адресов и результаты предыдущей одиночной проверки находятся в **SERVER_CHECK.md** и **server_check.json**. Их дата сохранена: 28 октября 2026 года. Тогда ответил 21 адрес; четыре адреса Riot не ответили за 900 мс.

Fortnite использует доменные диагностические endpoints. IP определяется асинхронно и фиксируется до следующего применения цели. VALORANT публикует адреса для tracert: ICMP Echo может фильтроваться. Узлы Valve — SDR-ретрансляторы; игровой UDP/SDR-протокол здесь не измеряется. Адрес Blizzard опубликован поддержкой в 2018 году и помечен как исторический диагностический адрес.

## Профили подключений

Выберите адрес, адаптер, режим, порт и дополнительные регионы. Нажмите **«Сохранить профиль…»** и задайте имя, например «Телефон USB» или «Домашний интернет». Выбор профиля восстанавливает эти параметры. Допускается до 50 профилей; замена и удаление требуют подтверждения в интерфейсе. Удаление профиля не удаляет историю сессий.

Если адаптер профиля исчез, применяется общий режим с уведомлением. Профиль хранит имя Windows-адаптера, поэтому после его переименования/переустановки может потребоваться обновление. Имя последнего профиля сохраняется между запусками.

## История, статистика и отчёты

Нажмите **«История / отчёты…»**. История локальная, по умолчанию за семь дней; в настройках доступны 1, 7 и 30 дней. Смена цели, режима, порта, адаптера или профиля начинает новую сессию. Дополнительные регионы записываются в ту же сессию отдельными точками. Сессия, не закрытая штатно, при следующем запуске помечается как прерванная.

Выберите сессию: график показывает всю сохранённую историю цели. Для больших сессий данные сводятся максимум к 600 интервалам; в каждом сохраняется максимальная задержка и наличие тайм-аутов/ошибок. Это график пиков по интервалам, а не отображение каждого пакета.

Выберите две строки через Ctrl+клик и нажмите **«Сравнить две сессии»**: доступны средняя задержка, P50, P95, потери/тайм-ауты, ошибки и число попыток. Сравнивайте сопоставимые адреса, режимы и условия подключения.

**«Экспорт CSV + HTML…»** создаёт два самостоятельных файла в выбранной папке. CSV содержит подробные измерения с временем UTC; HTML — понятный отчёт со сводной статистикой и ограничениями. Экспорт и вычисление сводок выполняются в фоне. CSV записывается потоково; большой отчёт не требует загрузки всех строк в память. Экспортируемые текстовые значения защищены от формул при открытии в Excel, HTML-значения экранируются.

P50 — медиана успешных измерений; P95 — уровень, ниже которого находится примерно 95% успешных измерений. Джиттер/разброс — среднее абсолютное изменение соседних успешных ответов, пропуски разрывают пары. Ошибки сокета/API исключаются из доли потерь, но показаны отдельно и влияют на цвет качества.

В режиме TCP измеряется время установки соединения с указанным открытым портом; соединение сразу закрывается без TLS, HTTP и игровых данных. Процент в этом режиме означает тайм-ауты подключений. Отказ закрытого порта является ошибкой, а не потерей пакета. Шлюз, контроль и дополнительные регионы остаются в режиме ICMP.

## Уведомления

В **«Настройки…»** включаются уведомления и задаются пороги задержки, потерь/тайм-аутов и разброса. По умолчанию уведомления выключены. Они относятся к выбранной цели: ухудшение подтверждается тремя последовательными плохими оценками после накопления хотя бы пяти попыток; восстановление — пятью хорошими. Повторные предупреждения ограничены двумя минутами.

Сообщения отображаются через трей и в строке состояния. Windows может скрыть всплывающие сообщения согласно своим настройкам; приложение не меняет системные разрешения и режим «Не беспокоить».

## Фоновые программы и DNS

«Выбрать фоновые приложения…» показывает известные загрузчики и клиенты синхронизации. Реальный трафик каждого процесса не измеряется. Принудительное завершение выполняется только после выбора и подтверждения; сохраните работу.

«Очистить DNS-кэш» выполняет только `ipconfig /flushdns`, проверяет результат и ограничивает ожидание восемью секундами. Сокеты и модем не сбрасываются, автоматического повышения прав нет. Очистка DNS не снижает RTT до числового IP.

## Где хранятся данные

Настройки и профили: `HKEY_CURRENT_USER\Software\USBNetController\DesktopWidget`. История `history.sqlite` и журналы `logs/controller.log` находятся в локальной папке данных приложения Windows; её можно открыть из меню трея. Журналы ограничены ротацией: основной файл до 2 МБ и три резервных.

История содержит диагностические адреса, задержки, имена профилей/адаптеров и трафик. Она не отправляется разработчику или в облако. Перед передачей отчёта проверьте его содержимое. Для лабораторного запуска папку данных можно переопределить переменной `USB_NET_DATA_DIR`.

При 30 днях и нескольких дополнительных точках база может занимать сотни мегабайт и больше. Старые записи автоматически удаляются, но размер файла SQLite не обязан сразу уменьшаться: свободные страницы используются повторно. Запись идёт пакетами через отдельный поток, ошибки и переполнение очереди показаны пользователю. Обычное закрытие дожидается очереди. При аварийном отключении питания последние записи могут не сохраниться.

## Проверка и сборка

Запуск всех тестов: `python -m unittest discover -v`. В подготовленной версии проходят **66 проверок**, включая регрессии четырёх ошибок аудита, профили, уведомления, локальный TCP, сохранение сессий, удержание истории, SQL-процентили, CSV/HTML, повреждённые записи и закрытие во время фонового экспорта. Тесты не завершают пользовательские процессы и не очищают настоящий DNS-кэш.

Краткая ускоренная проверка с номинальным интервалом 10 мс и имитированными ответами: 6299 запросов, 6064 сохранённые строки, 13 сессий, ни одной пропущенной строки. Окно продолжало обслуживать контрольный таймер. Это стресс-проверка примерно на 12 секунд, а не доказательство круглосуточной устойчивости. Подробности в VALIDATION.md.

Для сборки: `python -m pip install pyinstaller==6.22.3`, затем `python -m PyInstaller JitterScope.spec`. Готовая сборка x64 включает значок и метаданные версии. Основные тексты лицензий приложены; статус публичного выпуска и нерешённые вопросы лицензирования/подписи перечислены в RELEASE_STATUS.md.

## Переименование

Сборка носит имя JitterScope. Внутренний ключ настроек `USBNetController/DesktopWidget` и папка данных сохранены для совместимости с версией 2.0: история и профили не теряются. Для переопределения папки данных также доступна переменная `JITTERSCOPE_DATA_DIR`; прежняя `USB_NET_DATA_DIR` продолжает поддерживаться.
