Автор проекта: **SanyLok**. Авторская отметка: **© 2026 SanyLok — автор JitterScope**. Она включена в окно «О программе», README и метаданные исполняемого файла.

## Перед публичным распространением

- По поручению владельца для собственного кода выбрана GPL-3.0-only. Автор: SanyLok. Полный текст включён в LICENSE; сторонние компоненты сохраняют свои лицензии.
- В сборке используется доступная GPL-версия PyQt6. Способ продажи и способ лицензирования — разные вопросы. Для приложения с лицензией, несовместимой с GPL, Riverbank требует подходящую коммерческую лицензию PyQt. Точные условия: [официальный FAQ](https://www.riverbankcomputing.com/commercial/license-faq).
- Завершить проверку условий Qt и его сторонних компонентов для выбранной схемы поставки. Приложенные тексты лицензий — подготовка, а не замена этой проверки.
- Текущая сборка не подписана. Для цифровой подписи нужен сертификат и данные издателя владельца проекта; они не были предоставлены. Метаданные версии и контрольные суммы подготовлены отдельно.
- Испытать приложение на дополнительных компьютерах, Windows 10/11, разных телефонах, VPN, масштабах экрана и после сна/переподключения. Автоматические тесты и локальные стресс-проверки не доказывают отсутствие всех ошибок.
